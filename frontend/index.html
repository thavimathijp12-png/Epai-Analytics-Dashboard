About EPAI

EPAI (Employee Performance & Attrition Intelligence) is a professional workforce analytics platform.


Analytical Credibility

The "Analytical Attrition Risk Score" is a programmatic heuristic algorithm based on HR attributes (e.g., Overtime, Low Satisfaction). It is NOT a scientifically validated Machine Learning model. It serves as an analytical flag to direct HR attention.


Data Source

This is a portfolio project utilizing synthetic employee data running on a local Full-Stack Node.js and MongoDB architecture.
